# T06 — 股份权益、入账、可卖与计划调整

Status: TODO
Blocked by: T05

依据：[spec A16/A17](../../../1.spec.md#12-验收场景)、[架构 PriceBasis 与历史权益](../../../2.ARCHITECTURE.md)、[execution-v1](../../../3.EXECUTION_POLICY_V1.md)。交付跨日股份变化，不能用复权因子代替实际权益流水。

## 验收

- [ ] 用一个可手算合成送转/拆分事件，分别定义权益确认、除权、股份入账与可卖时点，并保存来源和版本。
- [ ] 未入账权益与持仓价值不重复计算；入账时冲减原权益、增加持仓，类别转换本身不创造资产（A16）。
- [ ] 股份已入账但尚不可卖时，hold 仍估值，rebalance 仅卖出可卖部分并说明原因；到可卖时点才允许余量卖出。
- [ ] 跨除权日根据已核验规则调整冻结计划及价格基准，保留原动作与调整前后记录；不能按次日价格重新求目标。
- [ ] 缺规则、日期或价基转换依据时暂停；不用前复权价格直接比较历史真实开盘价。
- [ ] 窗口结束保留持仓和未到账权益；不为了结束自动清零或卖出（A17）。
- [ ] 多日账户守恒、重复请求、时间可见性与 T05 现金权益回归通过。

## 范围与证据

只支持有证据且已实现的具体事件类型；未知类型显式暂停，不把一个合成例推广为全 A 股事件覆盖。完成证据为逐日权益、股数、可卖数量、价格基准和总资产对账。

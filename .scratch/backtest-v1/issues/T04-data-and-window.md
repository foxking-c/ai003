# T04 — 数据边界、正常受限与未知暂停

Status: TODO
Blocked by: T01

依据：[spec 第 5、8、10 节](../../../1.spec.md)、[execution-v1 D05/D08/D09/D11](../../../3.EXECUTION_POLICY_V1.md)。交付可观察的日期对齐、资格和结束行为，使用明确标注的合成日历与规则。

## 验收

- [ ] 仅非交易日按日历对齐；返回请求及实际范围；空区间、缺首日前一决策资料拒绝。不能为寻找齐全数据继续挪动日期。
- [ ] 已知停牌/价格限制形成正常未成交并估值；关键行情、估值或规则未知则暂停，不生成零奖励或正常训练样本（A15）。
- [ ] 停牌估值若使用陈旧值，须有显式规则和日期；陈旧值不得成交。缺退市处置依据不得自动清零或按最后价卖出。
- [ ] 合成/旧受限包的正式用途初始化被拒绝；演示与受限复现保留包限制，不能把 formal_backtest_allowed=false 改成 true（A19 负例）。
- [ ] 未来缺失统计、次日资格、全包根哈希不进入观测；历史规则版本和每字段 available_at 受决策时刻约束（扩展 A11/A12）。
- [ ] 窗口结束仍保留持仓，不自动清仓或 reset；truncated 与 terminated 独立计算。数据故障不是终止样本（A17）。
- [ ] 缺失与错误在公开 read 可查，冻结后的请求只能沿原动作恢复；输入身份变化不能覆盖旧包续跑。

## 范围与证据

不推断真实交易日历与行情资格。金额与状态输出需和 T01 共同回归；真实包正例由 E01/T11 承担。完成证据记录每个拒绝/暂停/正常受限/结束案例的输入身份和响应。

# T03 — 多股票现金不足的共同缩减

Status: TODO
Blocked by: T02

依据：[execution-v1 第 2–3 节](../../../3.EXECUTION_POLICY_V1.md#3-d01-的确定算法)。交付公开 step 中的确定分配行为，不能仅提交一个从未被账户调用的算法函数。

## 验收

- [ ] T 日计划上限先冻结，过滤开盘区间和已知交易限制后，按精确有理数断点共同缩放（A05/A06）。
- [ ] 两股各计划 200、价 10、合法量 100/200、每非零单费 5、现金 3010：各买 100，余款 1000；不分配为 200/100。
- [ ] 同例现金 2010 恰好买各 100；2009 两股都为零，费用也为零。
- [ ] 单股计划 1000、候选价 11、100 股递增、费 5、现金 10005：买 900、余款 100，原计划仍为 1000。
- [ ] 两股各计划 100、价 1、合法量 1–100、费 5、现金 110：各买 50，不能按简单比例取 52。
- [ ] 候选价格下跌不能买超计划；输入排列置换后，按证券对应的成交、费用与现金完全相同。
- [ ] 覆盖空集合、零现金、无合法量、不等步长数量、费用舍入边界；未知或非单调总支出规则暂停。
- [ ] 搜索、最终复核和实际扣款共用精确订单成本；不在试算时记账，不因缩成零而移除订单重新分配。
- [ ] 用小规模独立穷举参考核对搜索结果，再通过公开 step 核对账本，原验收回归通过。

## 范围与证据

不追求最高资金使用率，不增加余款优化策略；如实现等价高效搜索，需证明与断点参考一致。完成时保留 fixture 身份、手算五例、排列验证和账户输出；性能仅记录实际测量。

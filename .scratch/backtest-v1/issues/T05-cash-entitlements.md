# T05 — 现金权益的确认与到账

Status: TODO
Blocked by: T03, T04

依据：[spec 账户守恒](../../../1.spec.md#81-账户状态)、[架构第 7 节](../../../2.ARCHITECTURE.md#7-数据数值与运行记录)。交付跨日现金权益流水，并通过公开账户和买入行为证明资产不重复计算。

## 验收

- [ ] 合成事件明确登记、确认、除息、应收、支付日期、适用规则及证据/可用时刻，不能把它们合并为同一天。
- [ ] 在无其他价格变化的守恒案例中，股票因除息减少的价值与确认应收对应；应收未到账前不能用于买入（A16）。
- [ ] 支付日将应收转为现金，冲减原应收，转换本身不重复增加总资产或奖励。
- [ ] 在买入阶段前确已到账的现金可参与 T03 预算；同日稍后才到账的权益不可提前使用。
- [ ] 缺支付时点、基准转换或费用依据时暂停，不补猜日期；暂停后账户仍是最后已提交版本。
- [ ] T 日 Plan 与有依据的公司行动调整分开记录；未来事件不能泄露到 T 日 observation。
- [ ] 回放、同请求重试不重复确认或支付权益；T01/T03/T04 的验收继续通过。

## 范围与证据

先实现现金权益的具体规则，不创建通用事件插件。完成时给出逐日股票价值、应收、现金、资产、可用于买入预算的手算对账表。真实事件资格仍由 E01/T11 核验。

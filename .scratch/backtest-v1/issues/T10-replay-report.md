## 验收

- [ ] 每次回放创建独立 run，完整保存数据/规则/时间策略、实际费用/滑点/精度、源码身份、依赖锁、奖励/动作映射及种子；无 Git 时不虚构 commit。
- [ ] 同一输入、动作和身份产生按声明精度一致的每日账本、费用、净值及奖励；随机 run ID/路径等管理字段不参与经济结果相等性比较（A18）。
- [ ] 报告只从已提交账本生成；删除/重建导出文件不会改变数据库，暂停时不展示未提交候选结果。
- [ ] 报告包括累计/年化收益、最大回撤、每日资产、费用、换手、未成交统计、平均现金比例和最终持仓，明确年化、换手、短区间及权益估值口径。
- [ ] 用手算多日样例验证收益、回撤、换手和费用；奖励累计单独展示，无合格基准不生成超额收益。
- [ ] 数据用途、证券/日期范围、日线近似、容量和缺失限制进入报告；不把低换手或少成交自动评价为策略有效。
- [ ] 固定动作回放与重新调用模型生成动作明确区分；不通过重训或未来数据重新拟合“复现”旧动作。
- [ ] T01–T09 的全部合成验收通过，记录当前机器、证券/日期数量、耗时和内存基线，不自行宣称吞吐目标达标。

## 范围与证据

不建立交互仪表盘或性能优化框架。完成证据包含手算对账、两个独立 run 的比较、报告样例、全套合成回归和测量条件。

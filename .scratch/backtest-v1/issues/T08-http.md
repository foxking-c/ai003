## 验收

- [ ] FastAPI/Pydantic 的实际依赖组合锁定并可在当前 Windows 环境导入；本地服务默认 127.0.0.1、单 worker。
- [ ] 路径/正文运行身份一致；精确小数的 HTTP 字符串往返后与 Python Decimal 结果一致，无隐式浮点金额损失。
- [ ] 同一合成包及固定动作经 Python/HTTP 得到相同账户、成交、费用、奖励和结束标志。
- [ ] 非法输入与冲突、正常未成交、数据暂停在 HTTP 中可区分，暂停不包装成正常五元组。
- [ ] 通过真实 HTTP 场景验证丢失响应后的原请求重试、结束后的重放、丢 ID 后查询找回、同 ID 改内容拒绝（A09）。
- [ ] GET 只读已提交账户与允许的恢复信息；执行诊断不混入模型 observation。
- [ ] 结果端点先提供已提交事实；T10 的汇总报表后续接入，不另建权威账本。
